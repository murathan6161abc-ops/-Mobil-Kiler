## 📖 Hakkında

Bu proje, **Murathan Mollamehmetoğlu**'nun kişisel portfolio web sitesidir. Trabzon Fen Lisesi 9. sınıf öğrencisi olarak yazılım geliştirme ve yapay zeka alanlarındaki projelerimi ve yeteneklerimi sergilemek amacıyla oluşturulmuştur.

---

## ✨ Özellikler

- 🎨 **Modern & Premium Tasarım** — Glassmorphism efektleri ve gradient renkler
- 🌌 **Parçacık Animasyonu** — Canvas tabanlı interaktif arka plan
- ✨ **Cursor Glow Efekti** — Fareyi takip eden ışık efekti
- 📜 **Scroll Animasyonları** — Sayfada gezinirken ortaya çıkan elementler
- 💻 **Kod Yazma Animasyonu** — Hero bölümünde typing efekti
- 📊 **Animasyonlu Yetenek Barları** — Görsel yetenek gösterimi
- 🔢 **Sayaç Animasyonu** — Proje, dil ve deneyim istatistikleri
- 🐍 **Snake Oyunu** — Yerleşik oynanabilir yılan oyunu
- 📱 **Tam Responsive** — Mobil, tablet ve masaüstü uyumlu
- 🍔 **Mobil Menü** — Hamburger menü desteği
- 📧 **İletişim Formu** — Mesaj gönderme arayüzü

## 🛠️ Kurulum

Projeyi yerel ortamınızda çalıştırmak için:

1. **Repoyu klonlayın:**
   ```bash
   git clone https://github.com/KULLANICI_ADINIZ/portfolio.git
   ```

2. **Proje klasörüne gidin:**
   ```bash
   cd portfolio
   ```

3. **Tarayıcıda açın:**
   
   `index.html` dosyasını herhangi bir tarayıcıda açmanız yeterlidir. Herhangi bir sunucu veya build aracına gerek yoktur.

   Ya da VS Code ile **Live Server** eklentisini kullanabilirsiniz.
